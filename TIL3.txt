파이썬 조건문 if: 프로그램이 스스로 판단하게 만드는 법

- 조건문이란: 코드의 실행 흐름에 갈림길 만들기
- `if`: 조건이 참일 때만 실행
- 콜론(`:`)과 들여쓰기(공백 4칸)
- `if - else`: 둘 중 하나 고르기
- `if - elif - else`: 여러 갈래 중 하나 고르기
- 조건 순서의 중요성
- 중첩 `if`와 `and`/`or`/`not` 결합

#if

조건식의 결과가 `True`일 때만 아래 코드를 실행하고, `False`면 건너뜁니다. 
조건식은 앞서 배운 **비교 연산자와 논리 연산자의 결과**입니다. 
조건식 끝에는 반드시 콜론(`:`)을 붙입니다. 
콜론은 “지금부터 조건에 딸린 코드가 시작된다”는 신호입니다.

# else

 `if` 조건이 `False`일 때 실행되는 “그 외 전부”입니다. **조건식을 달 수 없고**, 단독으로 쓸 수도 없습니다. 
 반드시 위의 `if`와 **같은 들여쓰기 칸**에 있어야 쌍으로 인식됩니다.
갈림길의 “이쪽이 아니면 저쪽”입니다. 길이 두 갈래뿐이라 반드시 한쪽으로 갑니다.

# elif

`else if`의 줄임말입니다. 위의 조건이 모두 `False`일 때 “그럼 이 조건은?” 하고 다음 조건을 검사합니다. 
파이썬은 **위에서 아래로 검사하다가 처음 `True`가 나오는 블록 하나만 실행하고, 나머지는 건너뛰고 조건문을 끝냅니다.**
식당에서 “치킨 있으면 치킨, 없으면 피자, 그것도 없으면 라면”이라고 순서를 정해 주는 것입니다. 
치킨이 있으면 피자는 확인조차 안 합니다.

# if를 여러 개 나열 vs elif

`if`를 따로따로 여러 개 쓰면 **각각 독립적으로 검사**해서 여러 블록이 동시에 실행될 수 있습니다. `elif`로 이으면 **딱 하나만** 실행됩니다.
설문의 “해당하는 것을 모두 고르세요”(여러 개 `if`)와 “하나만 고르세요”(`elif`)의 차이입니다.

# 중첩 조건문과 조건 결합

 `if` 안에 또 `if`를 넣는 구조가 **중첩**입니다. 깊어질수록 읽기 어려워서, 보통 `and`/`or`로 한 줄에 합치거나, 이유별 안내가 필요하면 `elif`로 평평하게 펼칩니다.
 문 안에 또 문이 있는 구조입니다. 한 번에 “신분증, 티켓, 가방 검사”를 묶어서 하면 줄이 짧아집니다.


# 자주 발생하는 오류
콜론(:) 빠뜨림
=와 == 혼동
else에 조건을 달았거나 else만 단독으로 씀
elif 순서가 넓은 조건 먼저
if를 여러 개 나열해서 중복 실행
중첩 if가 3단계 이상
